## How I Used My Skills to Build This GitHub Profile

I set up this profile repository as a central place to show my learning, technical growth, and project work. Since the repository name matches my GitHub username, GitHub uses this `README.md` as the profile overview that appears at the top of my account.

I used organization and GitHub workflow skills to create the required `.github/workflows` folder structure and add a GitHub Actions workflow for the contribution snake animation. The workflow runs automatically on a schedule, can be triggered manually, and also runs when updates are pushed to the `main` branch.

I used documentation skills to keep the profile readable and structured. The README introduces who I am, explains what the repository is for, and includes the generated contribution animation so visitors can quickly understand that this profile is actively maintained.

I also used attention to detail to check naming requirements carefully. The root file is named `README.md`, the workflow file is named `snake.yml`, and the repository remote points to `RadhikaBhumireddi/RadhikaBhumireddi`, which is the special GitHub profile repository format.
